doc-engine Developer Documentation

A headless document layout and vector rendering engine for React and TypeScript that compiles directly to real, searchable PDFs. Zero Python backend, zero Puppeteer headless browsers, zero screenshots.

⚡
Pure TypeScript & JS

Runs anywhere: Browser, Web Workers, Node.js, Next.js API Routes, Vercel Serverless, and Edge runtimes.

🔍
Real Vector PDFs

Infinite vector sharpness at 1,000% zoom. Text is 100% searchable, selectable, and screen-reader accessible.

📐
Dual Coordinate Ergonomics

Code using web Top-Left (0,0) coordinates or native PDF Bottom-Left (0,0) coordinates with automatic transforms.

🚀
60 FPS Live Previews

Dual renderer renders directly to HTML5 Canvas in < 5ms for smooth live editing without recompiling binary PDF blobs.

📊
Tables, Grids & Flexbox

First-class primitives for itemized tables, auto column sizing, 2D grids, and flex row/column stacks.

📑
Auto-Pagination & Rules

Automatic multi-page splitting, repeating headers/footers, and print constraints like keepWithNext.

Why doc-engine?

Most document generators in web development suffer from severe architectural trade-offs:

  • Heavy Server Runtimes (Python / ReportLab / Puppeteer): Require 500MB+ Docker images, multi-language stacks, slow cold-starts, and expensive server infrastructure.
  • DOM Screenshot Tools (html2pdf, html2canvas): Convert pages into blurry raster images. Text cannot be selected or searched, and files balloon to 5MB–15MB.
  • React-Locked Libraries (@react-pdf/renderer): Cannot be used in plain Node.js scripts or CLI tools, and compiling binary PDF blobs on every keystroke causes noticeable UI lag.

doc-engine solves this by treating the Document AST and Layout Engine as the main core product. It decouples document representation from rendering targets, outputting to native vector PDFs via pdf-lib, instant HTML5 Canvas previews, or SVG graphics.

Architecture & Core Engine

The engine is built around a pure, serializable JSON Document AST (Abstract Syntax Tree). The layout pipeline processes text measurement, auto-layout flow, and page pagination before handing the calculated frame tree to any renderer.

┌─────────────────────────────────────────────────────────────────────────┐ │ DOCUMENT SPECIFICATION │ │ React JSX () OR Fluent API (createDocument()) │ └────────────────────────────────────┬────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────────────────────┐ │ JSON AST SPECIFICATION │ │ DocumentDefinition -> Pages -> Views / Text / Tables / Shapes / Grid │ └────────────────────────────────────┬────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────────────────────┐ │ LAYOUT ENGINE │ │ Text Wrap (AFM) ──► Flex / Grid Calculation ──► Table Column Auto-Size │ │ │ │ │ Pagination & Constraints Split │ └────────────────────────────────────┬────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────────────────────┐ │ PLUGGABLE RENDERERS │ ├──────────────────────────┬──────────────────────────┬───────────────────┤ │ PdfRenderer (Vector) │ CanvasRenderer (60 FPS) │ SvgRenderer (DOM) │ └──────────────────────────┴──────────────────────────┴───────────────────┘

Key Architectural Principles

  • Zero Native Dependencies: 100% pure TypeScript/JavaScript. No C++ native bindings, no Cairo, no node-gyp.
  • Top-Left Origin Transform: Native PDF graphics use Bottom-Left (0,0). doc-engine transforms coordinates automatically: Y_pdf = pageHeight - Y_screen - elementHeight.
  • AFM Font Metrics Cache: Precise line breaking and text width calculation using Standard 14 PostScript font metric tables.

Quickstart Guides

1. Pure TypeScript / Node.js Backend Workflow

Create and export a PDF document from a Node.js script, Express API endpoint, or background job worker:

typescript (generate-invoice.ts) 
import { createDocument, PdfRenderer } from '@worklabs05/doc-engine';
import fs from 'node:fs/promises';

async function generateInvoice() {
  const doc = createDocument({
    defaultPageSize: 'letter',
    coordinateOrigin: 'top-left',
  });

  doc.addShape({
    shapeType: 'rectangle',
    x: 40, y: 40, width: 532, height: 60,
    fillColor: '#0f172a', borderRadius: 6,
  });

  doc.addText({
    text: 'ACME SOFTWARE INC.',
    x: 60, y: 58, fontSize: 18, fontWeight: 'bold', color: '#ffffff',
  });

  const pdfBytes = await PdfRenderer.renderToBytes(doc.toDefinition());
  await fs.writeFile('invoice.pdf', pdfBytes);
}

generateInvoice();

2. Declarative React JSX Workflow

Compose documents with React components and trigger instant client-side PDF downloads using the usePDF hook:

tsx (InvoiceViewer.tsx) 
import React from 'react';
import { Document, Page, View, Text, usePDF } from '@worklabs05/doc-engine/react';

export function InvoiceComponent() {
  const invoiceDoc = (
    <Document defaultPageSize="letter">
      <Page backgroundColor="#ffffff">
        <View x={40} y={40} width={532} height={70} backgroundColor="#0f172a" borderRadius={6} padding={16}>
          <Text fontSize={22} fontWeight="bold" color="#ffffff">ACME CORP</Text>
        </View>
      </Page>
    </Document>
  );

  const { dataUrl, loading, download } = usePDF(invoiceDoc);

  return (
    <button onClick={() => download('invoice.pdf')}>
      {loading ? 'Compiling...' : 'Download Real Vector PDF'}
    </button>
  );
}

3. Next.js App Router (Serverless Route Handler)

Generate streamable PDFs on demand in Next.js without running heavy headless browsers:

typescript (app/api/invoice/route.ts) 
import { NextResponse } from 'next/server';
import { createInvoiceDocument } from '@worklabs05/doc-engine/examples';
import { PdfRenderer } from '@worklabs05/doc-engine';

export async function POST(req: Request) {
  const body = await req.json();
  const invoiceDoc = createInvoiceDocument(body);
  const pdfBytes = await PdfRenderer.renderToBytes(invoiceDoc);

  return new NextResponse(pdfBytes, {
    headers: {
      'Content-Type': 'application/pdf',
      'Content-Disposition': 'attachment; filename="invoice.pdf"',
    },
  });
}
