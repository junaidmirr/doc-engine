doc-engine Documentation

A headless document layout and vector rendering engine for React and TypeScript that compiles directly to real, searchable PDFs. Zero Python backend, zero Puppeteer headless browsers, zero screenshots.

⚡
Pure TypeScript & JS

Runs anywhere: Browser, Web Workers, Node.js, Next.js API Routes, Vercel Edge, and Cloudflare Workers.

🔍
Real Vector PDFs

Infinite vector sharpness at 1,000% zoom. Text is 100% searchable, selectable, and screen-reader accessible.

📐
Dual Coordinate Ergonomics

Code using web Top-Left (0,0) coordinates or native PDF Bottom-Left (0,0) coordinates with automatic transforms.

🚀
60 FPS Live Previews

Dual renderer renders directly to HTML5 Canvas in < 5ms for smooth live editing without recompiling binary PDF blobs.

📊
Tables, Grids & Flexbox

First-class primitives for itemized tables, auto column sizing, 2D grids, and flex row/column stacks.

📑
Auto-Pagination & Rules

Automatic multi-page splitting, repeating headers/footers, and print constraints like keepWithNext.

Why doc-engine?

Most document generators in web development suffer from severe architectural trade-offs:

  • Heavy Server Runtimes (Python / ReportLab / Puppeteer): Require 500MB+ Docker images, multi-language stacks, slow cold-starts, and expensive server infrastructure.
  • DOM Screenshot Tools (html2pdf, html2canvas): Convert pages into blurry raster images. Text cannot be selected or searched, and files balloon to 5MB–15MB.
  • React-Locked Libraries (@react-pdf/renderer): Cannot be used in plain Node.js scripts or CLI tools, and compiling binary PDF blobs on every keystroke causes noticeable UI lag.

doc-engine solves this by treating the Document AST and Layout Engine as the main core product. It decouples document representation from rendering targets, outputting to native vector PDFs via pdf-lib, instant HTML5 Canvas previews, or SVG graphics.

Architecture & Core Engine

The engine is built around a pure, serializable JSON Document AST (Abstract Syntax Tree). The layout pipeline processes text measurement, auto-layout flow, and page pagination before handing the calculated frame tree to any renderer.

┌─────────────────────────────────────────────────────────────────────────┐ │ DOCUMENT SPECIFICATION │ │ React JSX () OR Fluent API (createDocument()) │ └────────────────────────────────────┬────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────────────────────┐ │ JSON AST SPECIFICATION │ │ DocumentDefinition -> Pages -> Views / Text / Tables / Shapes / Grid │ └────────────────────────────────────┬────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────────────────────┐ │ LAYOUT ENGINE │ │ Text Wrap (AFM) ──► Flex / Grid Calculation ──► Table Column Auto-Size │ │ │ │ │ Pagination & Constraints Split │ └────────────────────────────────────┬────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────────────────────┐ │ PLUGGABLE RENDERERS │ ├──────────────────────────┬──────────────────────────┬───────────────────┤ │ PdfRenderer (Vector) │ CanvasRenderer (60 FPS) │ SvgRenderer (DOM) │ └──────────────────────────┴──────────────────────────┴───────────────────┘

Key Architectural Principles

  • Zero Native Dependencies: 100% pure TypeScript/JavaScript. No C++ native bindings, no Cairo, no node-gyp.
  • Top-Left Origin Transform: Native PDF graphics use Bottom-Left (0,0). doc-engine transforms coordinates automatically: Y_pdf = pageHeight - Y_screen - elementHeight.
  • AFM Font Metrics Cache: Precise line breaking and text width calculation using Standard 14 PostScript font metric tables.

Installation

Install doc-engine and its peer dependency pdf-lib via npm, pnpm, or yarn:

Terminal (Bash) 
npm install doc-engine pdf-lib

If you are using React components or hooks, install React dependencies:

Terminal (Bash) 
npm install doc-engine pdf-lib react react-dom
💡
Zero Native Compilers Needed
doc-engine runs seamlessly on Node.js 18+, Next.js, Web Workers, Vercel Serverless/Edge functions, and browser clients.

Quickstart Guides

1. Pure TypeScript / Node.js Backend Workflow

Create and export a PDF document from a Node.js script, Express API endpoint, or background job worker:

typescript (generate-invoice.ts) 
import { createDocument, PdfRenderer } from 'doc-engine';
import fs from 'node:fs/promises';

async function generateInvoice() {
  // 1. Initialize fluent document builder
  const doc = createDocument({
    defaultPageSize: 'letter',
    coordinateOrigin: 'top-left',
    metadata: { title: 'Invoice #INV-2026-001', author: 'Acme Inc' },
  });

  // 2. Add header banner shape
  doc.addShape({
    shapeType: 'rectangle',
    x: 40, y: 40, width: 532, height: 60,
    fillColor: '#0f172a', borderRadius: 6,
  });

  doc.addText({
    text: 'ACME SOFTWARE INC.',
    x: 60, y: 58, fontSize: 18, fontWeight: 'bold', color: '#ffffff',
  });

  // 3. Add itemized table
  doc.addTable({
    x: 40, y: 130, width: 532,
    columns: ['3fr', '1fr', '1fr'],
    zebra: true,
    header: {
      cells: [
        { content: 'Description', fontWeight: 'bold' },
        { content: 'Quantity', align: 'center', fontWeight: 'bold' },
        { content: 'Price', align: 'right', fontWeight: 'bold' },
      ],
    },
    rows: [
      { cells: [{ content: 'Cloud Architecture' }, { content: '20', align: 'center' }, { content: '$3,000.00', align: 'right' }] },
      { cells: [{ content: 'Engine Integration' }, { content: '10', align: 'center' }, { content: '$1,500.00', align: 'right' }] },
    ],
  });

  // 4. Render to real vector PDF bytes
  const pdfBytes = await PdfRenderer.renderToBytes(doc.toDefinition());
  await fs.writeFile('invoice.pdf', pdfBytes);
}

generateInvoice();

2. Declarative React JSX Workflow

Compose documents with React components and trigger instant client-side PDF downloads using the usePDF hook:

tsx (InvoiceViewer.tsx) 
import React from 'react';
import { Document, Page, View, Text, usePDF } from 'doc-engine/react';

export function InvoiceComponent() {
  const invoiceDoc = (
    <Document defaultPageSize="letter">
      <Page backgroundColor="#ffffff">
        <View x={40} y={40} width={532} height={70} backgroundColor="#0f172a" borderRadius={6} padding={16}>
          <Text fontSize={22} fontWeight="bold" color="#ffffff">ACME CORP</Text>
          <Text fontSize={12} color="#38bdf8">INVOICE #INV-2026-001</Text>
        </View>

        <Text x={40} y={135} width={400} fontSize={12} color="#334155">
          Due Date: October 15, 2026
        </Text>

        <Text x={40} y={170} fontSize={16} fontWeight="bold" color="#0f172a">
          Amount Due: $4,500.00
        </Text>
      </Page>
    </Document>
  );

  const { dataUrl, loading, download } = usePDF(invoiceDoc);

  return (
    <div>
      <button onClick={() => download('invoice.pdf')} disabled={loading}>
        {loading ? 'Compiling PDF...' : 'Download Real PDF'}
      </button>
      {dataUrl && <iframe src={dataUrl} style={{ width: '100%', height: '600px' }} />}
    </div>
  );
}

3. Next.js App Router (Serverless Route Handler)

Generate streamable PDFs on demand in Next.js without running heavy headless browsers:

typescript (app/api/invoice/route.ts) 
import { NextResponse } from 'next/server';
import { createInvoiceDocument } from 'doc-engine/examples';
import { PdfRenderer } from 'doc-engine';

export async function POST(req: Request) {
  const body = await req.json();
  const invoiceDoc = createInvoiceDocument(body);
  const pdfBytes = await PdfRenderer.renderToBytes(invoiceDoc);

  return new NextResponse(pdfBytes, {
    headers: {
      'Content-Type': 'application/pdf',
      'Content-Disposition': 'attachment; filename="invoice.pdf"',
    },
  });
}

Layout & Flow Engine Details

Containers & Views (<View>)

Containers define precise bounding boxes, background fills, borders, padding, and rounded corners:

tsx 
<View
  x={40} y={50} width={500} height={120}
  backgroundColor="#f8fafc"
  borderColor="#cbd5e1"
  borderWidth={1}
  borderRadius={8}
  padding={[12, 16]}
>
  {/* Nested view or text content */}
</View>

Text Flow & Typography

Text wrapping strictly respects container maxWidth using built-in font metrics (AFM tables). Unbroken strings (such as long URLs) are split using an $O(\log N)$ binary search character fitting algorithm so they never clip or overflow margins:

tsx 
<Text
  width={450}
  fontSize={12}
  lineHeight={1.45}
  letterSpacing={0.2}
  color="#334155"
  align="justify"
  maxLines={5}
>
  Your long paragraph flows here across multiple lines automatically...
</Text>

Flex Layouts (Row / Column)

Position items sequentially with automatic spacing gaps, padding, and cross-axis alignments:

tsx 
<View layout="flex" flexDirection="row" gap={16} alignItems="center">
  <Shape shapeType="circle" width={36} height={36} fillColor="#0284c7" />
  <View layout="flex" flexDirection="column" gap={4}>
    <Text fontSize={13} fontWeight="bold">Alex Turner</Text>
    <Text fontSize={10} color="#64748b">Staff Architect</Text>
  </View>
</View>

Grid Layouts

Arrange items in multi-column grids with 2D gaps (row gap and column gap):

tsx 
<Grid columns={3} gap={[12, 16]} width={532}>
  <Card title="Revenue" value="$42.8M" />
  <Card title="Gross Margin" value="76.4%" />
  <Card title="Active Users" value="1.2M" />
</Grid>

Tables with Zebra Striping

First-class table elements supporting fractional column definitions (e.g. ['2fr', 80, 100]), zebra background striping, padding, and cell align:

tsx 
<Table
  width={532}
  columns={['3fr', '1fr', '1fr']}
  zebra={true}
  header={{
    cells: [
      { content: 'Item', fontWeight: 'bold' },
      { content: 'Quantity', align: 'center', fontWeight: 'bold' },
      { content: 'Price', align: 'right', fontWeight: 'bold' },
    ],
  }}
  rows={[
    { cells: [{ content: 'Enterprise License' }, { content: '1', align: 'center' }, { content: '$12,000.00', align: 'right' }] },
    { cells: [{ content: 'Support SLA' }, { content: '12', align: 'center' }, { content: '$3,600.00', align: 'right' }] },
  ]}
/>

Auto-Pagination Engine

When flow content exceeds printable height, the engine splits content across multiple pages automatically while observing document margins.

typescript 
import { paginateElements } from 'doc-engine';

const pages = paginateElements({
  elements: flowElementsList,
  pageWidth: 612,
  pageHeight: 792,
  margins: { top: 40, bottom: 40, left: 40, right: 40 },
  repeatHeadersAndFooters: true,
});

Dynamic Headers & Footers

Bind running headers and footers to every page with automatic page numbering macros {pageNumber} and {totalPages}:

typescript 
const doc = createDocument({
  defaultPageSize: 'letter',
  headerElement: {
    type: 'text',
    text: 'Confidential Business Report',
    x: 40, y: 20, fontSize: 9, color: '#94a3b8',
  },
  footerElement: {
    type: 'text',
    text: 'Page {pageNumber} of {totalPages}',
    x: 40, y: 760, fontSize: 9, align: 'center', color: '#94a3b8',
  },
});

Layout & Page Break Constraints

Fine-tune print flow using standard pagination constraints:

Constraint Property Type Description
pageBreakBefore boolean Forces a page break immediately prior to rendering this element.
pageBreakAfter boolean Forces a page break immediately after rendering this element.
pageBreakInside 'auto' \| 'avoid' Pushes the entire element to the next page if it doesn't fit completely on the current page.
keepWithNext boolean Prevents a section header from being orphaned at the bottom of a page without its subsequent content.

React Hooks (usePDF, useDocument)

usePDF(docInput, options?)

Asynchronously compiles a Document AST or JSX tree into PDF bytes, Blobs, and data URLs:

tsx 
const { pdfBytes, blob, dataUrl, loading, error, download } = usePDF(myDocument);

useDocument(initialDoc?)

React hook managing stateful document editing with atomic undo/redo history:

tsx 
const { document, addElement, updateElement, removeElement, undo, redo, canUndo, canRedo } = useDocument(initialDoc);

<DocumentViewer> Preview Component

Renders a 60 FPS HTML5 Canvas live preview with interactive zoom and PDF download controls:

tsx 
import { DocumentViewer } from 'doc-engine/react';

<DocumentViewer
  document={myDoc}
  initialScale={1.0}
  showToolbar={true}
  className="rounded-lg shadow-xl"
/>

Full API Reference

Core Engine API (doc-engine)

Function / ClassSignature / MethodDescription
createDocument(options?) (options?: DocumentOptions) => DocumentBuilder Instantiates a fluent document builder.
DocumentEngine new DocumentEngine(def?: DocumentDefinition) Stateful manager with CRUD methods (addElement, updateElement, removeElement) and history.
PdfRenderer.renderToBytes(def) (def: DocumentDefinition) => Promise<Uint8Array> Renders document AST into raw binary vector PDF bytes.
PdfRenderer.renderToBlob(def) (def: DocumentDefinition) => Promise<Blob> Renders document AST into a browser Blob object.
CanvasRenderer.renderToCanvas(def, canvas, options?) (def: DocumentDefinition, canvas: HTMLCanvasElement, options?: CanvasRenderOptions) => void Renders document AST onto an HTML5 2D Canvas context at 60 FPS.
SvgRenderer.renderToSvg(def, pageIndex?) (def: DocumentDefinition, pageIndex?: number) => string Exports document AST page into an SVG string.
